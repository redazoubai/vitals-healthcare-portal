# vitals-healthcare-portal

# Welcome to my project

--------------------------------

Vitals is a web based healthcare application designed to provide a centralized platform for managing medical services and records.

# Features

* Searchable healthcare provider directory
* Appointment scheduling system
* Digital medical records
* Print to PDF functionality for documents
